# 游戏策划大纲

- 项目名称：first game
- 文档版本：v2
- 更新日期：2026-10-05
- 内容依据：本次策划讨论中已确认的玩法方向。
- 文档用途：理解游戏的基础玩法。具体算法、数值和实现细节后续逐项讨论。

本文描述后续开发的目标玩法。当前项目仍是移动、射击和击杀史莱姆的基础原型，以下新增系统尚待开发。

## 1. 游戏概述

这是一款单人、像素风的 2D 平面游戏，玩法朝塔防加肉鸽方向发展。

地图中央有一座水晶。玩家亲自移动和战斗，保护水晶，抵御逐波增强的敌人。击杀敌人获得金币，再通过补给、道具和随机强化提升本局能力。

游戏的主要乐趣包括走位战斗、吸引和处理敌人、保护水晶，以及根据随机强化组合出不同打法。

## 2. 核心流程

1. 开局选择职业，进入守护水晶的战斗。
2. 敌人按波次进攻。玩家移动、攻击，并利用仇恨机制减轻水晶压力。
3. 击杀敌人掉落金币，金币用于购买补给、道具、强化和付费刷新。
4. 完成一波后，进入等待下一波的倒计时阶段，此时开放强化购买。
5. 玩家在有限时间内决定购买强化、刷新候选，或留下金币用于之后的补给和买活。
6. 波间倒计时结束，下一波自动开始，强化购买关闭。
7. 波次推进时，商店免费更新未锁定的强化槽位，并重置付费刷新次数和价格。
8. 玩家死亡后进入复活等待，战斗继续；水晶被摧毁时，本局失败。

## 3. 水晶与玩家

### 3.1 水晶

- 水晶位于地图中央，拥有生命值，是玩家需要保护的目标。
- 敌人攻击水晶会使其失去生命值。
- 水晶被摧毁是本局唯一的失败条件。
- 水晶可通过购买修复恢复生命，也可以通过强化获得攻击能力等防守效果。

### 3.2 玩家

- 玩家拥有自己的血条，受到伤害后失去生命值。
- 玩家通过移动选择攻击位置、躲避伤害、拦截敌人和吸引仇恨。
- 玩家生命耗尽后死亡，暂时无法移动和攻击，进入复活倒计时。
- 玩家死亡期间，敌人继续进攻，水晶和已经生效的防守效果继续工作。

### 3.3 复活与买活

- 普通复活需要等待倒计时结束。
- 本局死亡次数越多，复活等待时间越长。
- 玩家可以在死亡期间打开商店，花金币买活，立即结束复活等待。
- 买活不重置本局累计死亡次数；本局买活次数越多，费用越高。
- 普通复活和买活后都提供短暂无敌，并有清楚的视觉提示。

## 4. 操作与战斗

- 保留按键移动、按键攻击的操作方式。
- 移动同时承担生存、调整攻击位置和控制敌人位置的作用。
- 不同职业通过攻击方式、攻击方向和作战距离形成差异。
- 枪手射程较长，但攻击方向受限，需要通过走位对准敌人。
- 近战可以包含周围或环绕攻击，法师可以包含锁定目标的法术。
- 商店由独立快捷键打开，随时可用，不限制玩家与水晶的距离。
- 打开商店后游戏不暂停，活着的玩家仍能移动和攻击。
- 道具通过快捷操作使用，具体键位和攻击操作细节后续确定。

## 5. 职业与成长倾向

职业逐步扩展为枪手、近战和法师。每个职业保留两个主要成长倾向，玩家在局内通过购买强化形成自己的打法。

| 职业 | 成长倾向 | 基础定位 |
|---|---|---|
| 枪手 | 机枪倾向 | 偏向射速和持续输出 |
| 枪手 | 火箭筒倾向 | 偏向攻击范围和范围伤害 |
| 近战 | 刺客倾向 | 灵活、高伤害，偏向闪避和机动 |
| 近战 | 战士倾向 | 能力数值较高、相对笨重，偏向承伤和吸引仇恨 |
| 法师 | 法术倾向 | 偏向玩家直接施法作战 |
| 法师 | 召唤倾向 | 偏向通过召唤物作战 |

“机枪”“火箭筒”等名称用于表达成长倾向，不代表必须更换成某种武器或进入互斥路线。

同一职业的两个倾向可以同时发展，通用强化与职业强化可以自由组合。例如射速与攻击范围、闪避与吸引仇恨、法术与召唤，都可以在同一局里共同成长。

## 6. 波次、敌人与仇恨

### 6.1 波次与敌人

- 每波敌人的整体压力逐步提高。
- 通过敌人强度、数量和类型组合产生变化。
- 不同敌人应带来不同的处理优先级和应对方式。
- 敌人类型可以围绕普通群体、快速突进、重甲承压、猎杀玩家和攻击水晶等方向扩展，具体名单后续确定。

### 6.2 仇恨机制

- 敌人会受到玩家吸引，仇恨影响其攻击目标。
- 采用混合目标机制，不同类型敌人对玩家和水晶的偏好不同。
- 普通敌人主要向水晶进攻，也能被玩家吸引；猎杀型敌人更主动追击玩家，攻城型敌人更执着于水晶。
- 仇恨可以融入职业特色：战士更容易吸引普通敌人，减少水晶压力；刺客可以通过机动或技能脱离仇恨；召唤物可以分担部分仇恨。
- 玩家可以通过引怪和牵制，为水晶争取时间。

## 7. 金币与肉鸽强化

### 7.1 金币用途

金币来自击杀敌人后的掉落，用于即时补给、购买道具、购买强化、买活和刷新强化候选。

金币需要在成长与救急之间分配。玩家可以集中提升某个方向，也可以同时发展多个方向或留下应急资金。

### 7.2 强化分类

- 通用强化：适用于各职业，包括水晶攻击、防守等方向。
- 职业强化：围绕当前职业的主要成长倾向展开。
- 组合强化：少量连接同一职业两个成长倾向的效果，让已有能力相互配合。

强化既包含能力提升，也可以改变攻击方式或带来新的作战效果。具体强化名单后续讨论。

### 7.3 强化组合与出现机会

- 强化允许组合，职业成长倾向不设置互斥限制。
- 通过价格、强化深度、触发条件和敌人差异，平衡专精与混搭。
- 每个强化有不同的出现概率，概率随波次进展变化。
- 核心强化需要有稳定的出现机会，其必出控制算法留到后续讨论。
- 已获得的强化持续作用于本局，不会因商店刷新或波次推进而消失。

## 8. 商店

### 8.1 使用方式

- 商店可通过快捷键随时打开，不需要站在水晶旁。
- 打开商店不暂停时间，不影响玩家移动和攻击。
- 商店分为即刻生效、道具、强化三个方向。
- 强化区的购买和付费刷新只在波间倒计时阶段开放。

### 8.2 商品分类

| 分类 | 用途与示例 | 购买时间 |
|---|---|---|
| 即刻生效 | 购买后立即结算，例如玩家回血、水晶修复、买活 | 随时可买，按当前状态使用 |
| 道具 | 买入后留待使用，例如手雷、燃烧瓶 | 随时可买 |
| 强化 | 购买后获得本局持续生效的通用强化、职业强化或组合强化 | 仅波间倒计时阶段 |

### 8.3 强化槽位与购买

- 强化区固定有三个槽位。
- 购买某个强化后，玩家获得其效果，对应槽位变空。
- 购买不会自动补充新选项，空槽位需要手动刷新或等到下一波更新才会出现新候选。
- 一个波间可以继续购买其他可用槽位的强化。

### 8.4 锁定

- 强化选项提供小锁，玩家可以保留暂时买不起或准备之后购买的选项。
- 锁定选项继续占用原槽位，其效果和价格保留。
- 手动刷新和跨波更新都不会替换锁定选项。
- 玩家可以解除锁定；购买后该槽位变空并解除锁定。

### 8.5 付费刷新与跨波更新

- 手动刷新消耗金币，重新生成所有未锁定槽位的候选，包括空槽位。
- 同一波内成功刷新越多，后续刷新越贵。
- 刷新使用当前波次对应的强化出现概率，不延长波间倒计时。
- 进入下一波时，商店免费更新一次，除锁定选项外，其余槽位全部刷新。
- 下一波重置付费刷新次数和价格，恢复基础刷新价。
- 跨波时金币余额和已获得的强化继续保留。

## 9. 画面与界面

- 延续像素风和 2D 平面表现。
- 战斗界面需要清楚展示玩家血量、水晶血量、金币和当前波次。
- 波间展示下一波倒计时，死亡期间展示复活倒计时。
- 商店清楚区分商品类别，展示强化槽位、空位、价格、锁定状态和当前刷新价格。
- 商店界面需要兼顾观察战场和继续操作角色。
- 不同职业、攻击效果和敌人需要有可辨认的表现。

## 10. 后续讨论范围

本大纲只记录已确认的基础设计。职业技能、强化条目、道具和敌人名单、金币收集方式、操作键位、波次编排、胜利目标及结算表现，后续逐项讨论。

生命、伤害、射速、价格、复活等待、无敌时长、波间时长、概率及其变化方式、仇恨和核心强化必出算法等具体内容，也在后续单独确定。

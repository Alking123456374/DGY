# 项目协作规则

本文件适用于本项目及其所有子目录。后续任务按以下规则执行。

## 1. 输出要求

- 语言：简体中文。
- 文风：直接、干脆、白话，不堆术语，不绕弯子。
- 文件命名：使用 `日期_主题_版本`，保留对应扩展名。日期按 `MMDD` 格式，版本按 `v1`、`v2` 等编号，例如 `0610_codex教程_v1.md`。
- 所有产出文件放到本项目对应子目录，不要散落在根目录。
- 本规则入口文件是例外：固定命名为 `AGENTS.md`，放在项目根目录。

## 2. 工作原则

1. 接到任务先列计划，等用户确认后再执行。
2. 改文件前先说明要改什么、为什么。
3. 任务完成后报告生成或修改了哪些文件，以及文件放在哪里。
4. 不确定的事直接问用户，不要自己猜着做。
5. 同一个错误不犯第二次。只有用户明确要求时，才将纠正内容或偏好记入本文件第 7 节；未明确要求时，不自动新增偏好记录。

## 5. 安全红线

- 永远不删除文件。需要移除的文件，只移动到本项目根目录下的 `trash/` 目录；目录不存在时先创建。
- 不碰本项目文件夹以外的任何文件。
- 涉及发布、发送邮件、花钱的操作，必须先经用户明确确认。

## 6. 代码注释

- 代码注释使用中文。
